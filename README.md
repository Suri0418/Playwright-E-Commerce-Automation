# Playwright E-Commerce Automation Testing

## Project Description
This project demonstrates automated testing of an E-Commerce website using Playwright with TypeScript.

## Technologies Used
- Playwright
- TypeScript
- Node.js
- GitHub

## Test Scenarios
- Login Test
- Product Search
- Add to Cart
- Checkout Process
- Logout Test

## How to Run Tests
Install dependencies:

npm install

Run tests:

npx playwright test

View report:

npx playwright show-report
